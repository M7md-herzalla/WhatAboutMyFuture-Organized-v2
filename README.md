# ماذا عن مستقبلي؟ 🎓

موقع عربي يساعد طلاب المرحلة الثانوية على اكتشاف ميولهم ومهاراتهم، والتعرّف على التخصصات الجامعية والحقول الأكاديمية لاتخاذ قرارات أكثر وعيًا بشأن مستقبلهم.

## ✨ المميزات

- اختبارات تفاعلية لاستكشاف الميول والمهارات والسمات الشخصية وعادات التعلّم.
- تحليل إجابات الطالب بالذكاء الاصطناعي وتقديم اقتراحات أكاديمية.
- مساعد ذكي للإجابة عن الأسئلة المتعلقة بالتخصصات والمسارات الدراسية.
- استعراض الجامعات والكليات والتخصصات الجامعية.
- البحث والفلترة ضمن معلومات القبول والساعات المعتمدة والرسوم الدراسية.
- عرض الحقول الأكاديمية والمواد المرتبطة بها.
- دعم الوضعين الفاتح والداكن.

## 🛠️ التقنيات المستخدمة

- **HTML:** بناء الصفحات وتنظيم المحتوى.
- **CSS:** تصميم الواجهات ودعم الثيم الفاتح والداكن.
- **JavaScript:** إدارة التفاعلات والاختبارات والبحث والفلترة.
- **APIs وFetch API:** التواصل مع خدمات الذكاء الاصطناعي وإرسال الطلبات واستقبال النتائج.
- **Google Gemini AI:** تشغيل المساعد الذكي وتحليل الإجابات.
- **JSON:** تبادل البيانات بين الموقع والخدمات الخارجية.
- **LocalStorage:** حفظ تفضيلات المستخدم وحالة إنجاز الاختبارات.
- **Cloudflare Workers:** الوسيط بين الموقع وخدمة الذكاء الاصطناعي.

## 🚀 التشغيل محليًا

1. حمّل المشروع أو انسخ المستودع.
2. افتح مجلد المشروع باستخدام VS Code.
3. شغّل ملف `index.html` باستخدام إضافة Live Server.

تتطلب خدمات الذكاء الاصطناعي اتصالًا بالإنترنت وتوفّر خدمة الـ API المرتبطة بالمشروع.

## 📌 ملاحظات

نتائج الاختبارات واقتراحات الذكاء الاصطناعي أدوات مساعدة، ولا تغني عن الإرشاد الأكاديمي المتخصص.

قد تتغير معدلات القبول والرسوم والخطط الدراسية؛ يُرجى الرجوع إلى المصادر الرسمية للجامعات قبل اتخاذ أي قرار.
