# ماذا عن مستقبلي؟ — النسخة المنظمة

## ابدأ من هنا

1. فك الملف المضغوط داخل مجلد جديد. هذه نسخة مشروع كاملة، وليست ملفات تحديث تُخلط مع المجلد القديم.
2. افتح مجلد المشروع الذي يحتوي index.html باستخدام VS Code.
3. اضغط بزر الفأرة الأيمن على index.html واختر Open with Live Server.
4. جرّب صفحة الحقول بالكتابة في مربع البحث، ثم جرّب الثيم والتنقل بين الصفحات.

الهيدر والفوتر يتم تحميلهما من ملفات مشتركة باستخدام fetch، لذلك شغّل المشروع عبر Live Server أو استضافة HTTP مثل Netlify؛ لا تفتحه بالنقر المزدوج كرابط file://.

لا تحتاج npm أو Vite أو React لتشغيل الواجهة. المشروع بقي HTML وCSS وJavaScript.

## أين أعدّل؟

- الهيدر: shared/header.html.
- الفوتر: shared/footer.html.
- ألوان الموقع وأحجام العناوين: css/theme.css.
- تصميم مربع بحث الحقول والاقتراحات: css/pages/fields.css.
- البحث والاقتراحات: js/pages/fields.js.
- خيارات الجامعات والكليات ونتائجها: js/pages/admission.js، والبيانات في js/data/universities.js.
- الأسئلة: js/data/questions.js.
- تعليمات تحليل AI: Backend/prompts/analysisPrompt.js ثم إعادة نشر الـWorker.
- رابط خدمة AI: js/config.js. يستخدمه الشات وتحليل الاختبارات.

## ما الذي تم إصلاحه؟

- إزالة التكرار بين الهيدر والفوتر والثيم في الصفحات الـ91.
- فصل CSS وJavaScript عن HTML، وإزالة الاستدعاءات القديمة لملفات CSS غير الموجودة.
- توحيد أسماء majorInput وsuggestionsList وsearchBtn؛ لا يوجد حقلان أو تعريفان متعارضان.
- الحفاظ على مربع البحث الدائري، مع ظهور القائمة تحته دون قصها بـ overflow: hidden.
- اقتراحات تعمل بالعربية مع تجاهل الهمزات والتشكيل، واختيار بالماوس أو لوحة المفاتيح.
- حفظ الثيم والتنقل الصحيح من الصفحات داخل مجلد majors/.
- فلاتر القبول تعمل مع نص البحث، والكليات تُستخرج من سجلات الجامعة المختارة.
- المطابقة الدقيقة للكلية تمنع خلط كلية العلوم بكلية العلوم التربوية.
- استعادة حالة الاختبارات المكتملة وزر التحليل بعد تحديث الصفحة.
- منع إرسال رسالتين في الشات في الوقت نفسه، وتحديد التاريخ المرسل بما يلائم حد خدمة الـWorker.
- تصحيح مسار شعار جامعة الزرقاء إلى الصورة الموجودة.

تم استعادة 25 صفحة تخصص ذات أسماء عربية من ملفات المشروع الأصلية، مع الحفاظ على محتواها. كل رابط تخصص في دليل الكليات يفتح الصفحة المخصصة له داخل majors/، وصفحة الحقول تبقى مستقلة. صُحّح أيضًا رابط الهندسة الكيميائية ليصل إلى صفحتها الصحيحة.

## البيانات والذكاء الاصطناعي

بيانات المشروع الحالية تضم 912 سجل قبول و169 مدخلًا في دليل الحقول. بعض سجلات القبول مكرر وبعض التخصصات غير مسجل؛ لم نضف أو نغيّر المعدلات والرسوم أو ندّعِ اكتمال البيانات الرسمية.

الواجهة تستخدم عنوان Cloudflare الموجود مسبقًا في js/config.js، ولا تحتوي مفتاح API. ملفات Backend وWorker موجودة للمراجعة والتطوير. إذا احتجت خادم Node المحلي، ثبّت اعتمادياته داخل Backend وأضف ملف .env الخاص بك؛ يوجد .env.example يوضح أسماء المتغيرات فقط. لا يحتاج استخدام Worker المنشور إلى تشغيل خادم Node محليًا.

قبل رفع النسخة الجديدة إلى Netlify تأكد أنها تعمل محليًا. عند السحب والإفلات ارفع محتويات مجلد المشروع الذي يحتوي index.html. وإذا تستخدم Git، ارفع الملفات المنظمة إلى المستودع المرتبط بالموقع. تأكد أن دليل النشر هو المجلد الذي يحتوي index.html؛ الواجهة لا تحتاج أمر build.

لا تعتمد على بيانات المعدلات أو التوصيات بوصفها مصدرًا رسميًا محدثًا؛ هذه النسخة تنظّم المشروع وتحافظ على بياناته الحالية.
